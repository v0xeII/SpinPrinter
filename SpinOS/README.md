# SpinOS: свой образ системы для принтера (Raspberry Pi 3B)

Человек записывает один файл на карту, вставляет её в Pi и включает принтер. Никаких настроек
в файлах, никакого SSH.

> **Статус: собрано по чертежу, на железе ещё не запускалось.** Buildroot принимает все
> настройки, но что Pi с этим образом загрузится, покажет первая проба на карте.

## Что внутри

- **Linux 6.12 от Raspberry Pi с PREEMPT_RT** (реальное время), собранный Buildroot 2026.02.3.
- **Система только для чтения** (squashfs): питание можно выдёргивать когда угодно. Всё, что
  меняется (видео, настройки, журнал, Wi-Fi), лежит на разделе `/data`, и SpinPi пишет туда
  так, что при обрыве питания старый файл остаётся целым.
- **Проектор чёрный с момента включения:** нет радужного квадрата (`disable_splash=1`), нет
  текстовой консоли и пингвина на HDMI (выключены в ядре), консоль только на UART-пинах.
- **SpinProj на отдельном ядре CPU:** ядро 3 убрано из общего расписания (`isolcpus=3`),
  SpinProj работает на нём с приоритетом реального времени. Частота CPU постоянная.
- **Wi-Fi без настроек:**
  1. Первое включение: принтер раздаёт свою сеть **SpinSlicer-XXXX**, а экран ESP32 показывает
     QR-код этой сети. Навёл телефон, подключился, страница принтера открылась сама.
  2. На странице: «Найти сети» → выбрать домашнюю → пароль → «Подключить».
  3. Дальше принтер сам подключается к дому, страница: `http://spinslicer.local`.
     Если сеть пропала или пароль неверный, через минуту снова появится SpinSlicer-XXXX.
- **SSH выключен.** Включается, если положить свой ключ в `/data/ssh/authorized_keys`.
  Паролей нет вообще.

## Разделы карты

| | | |
|---|---|---|
| 1 | `SPINBOOT` (FAT, 48 МБ) | прошивка Pi, ядро, `config.txt`, `cmdline.txt` |
| 2 | корень (squashfs, только чтение) | система + SpinPi + SpinProj |
| 3 | `SPINDATA` (ext4) | `/data`; при первом включении растягивается на всю карту |

## Как получить образ

**Проще всего: GitHub Actions** (когда проект будет на GitHub).
1. Вкладка **Actions** → **spinos** → **Run workflow**. Сборка идёт 1–2 часа.
2. Готовый `spinos-rpi3.img.xz` в разделе **Artifacts** этого запуска.
3. Если поставить тег `v0.1.0`, образ сам попадёт в **Releases**, и его сможет скачать любой.

**На своём компьютере** (нужно ~15 ГБ места и 1–2 часа; путь к папке без пробелов!):
```bash
wget https://buildroot.org/downloads/buildroot-2026.02.3.tar.xz
tar xf buildroot-2026.02.3.tar.xz
make -C buildroot-2026.02.3 BR2_EXTERNAL=$PWD/SpinOS O=$PWD/out spinos_rpi3_defconfig
make -C buildroot-2026.02.3 O=$PWD/out
```
Образ: `out/images/sdcard.img`.

**Записать:** Raspberry Pi Imager → «Выбрать ОС» → «Use custom» → `spinos-rpi3.img.xz` →
карта → «Записать». Настройки Imager (имя, Wi-Fi, SSH) для SpinOS не нужны.

## Что проверить на первой карте

1. Проектор (или монитор) **не светит** от включения до печати: ни радуги, ни текста.
2. Через сколько секунд после включения открывается страница (цель порядка 10 с).
3. Сеть SpinSlicer-XXXX появилась, QR-код на экране ESP32, страница открылась сама.
4. Подключение к домашней сети, `spinslicer.local` открывается.
5. Раздел `/data` вырос на всю карту (`df -h /data` по SSH).
6. `spinproj bench --rt --cpu 3`: цифры vsync и подготовки кадра (нужен SSH-ключ, см. выше).
7. Выдернуть питание посреди загрузки видео: после включения всё на месте.

Если что-то не так, лог SpinPi лежит в `/tmp/spinpi.log`, а при подключении USB-UART к пинам
14/15 (115200) видна вся загрузка.

## Файлы

| | |
|---|---|
| `configs/spinos_rpi3_defconfig` | что входит в систему |
| `board/spinos/config.txt`, `cmdline.txt` | загрузка Pi: чёрный экран, KMS, ядро 3 для проектора |
| `board/spinos/linux.fragment` | ядро: PREEMPT_RT, без консоли и логотипа, постоянная частота |
| `board/spinos/rootfs_overlay/usr/sbin/spinnet` | Wi-Fi: дом или своя точка доступа |
| `board/spinos/rootfs_overlay/etc/init.d/S01data` | раздел `/data`, рост при первом включении |
| `board/spinos/post-build.sh` | автозапуск SpinPi (перезапускается сам, если упадёт) |
| `package/spinpi`, `package/spinproj` | как Buildroot ставит наши программы |
