# SpinPi: Raspberry Pi для CAL-принтера SpinSlicer

**Русский** · [English](README.en.md)

Печать без флешки: Pi подключена к Wi-Fi, на экране принтера появляется **QR-код**,
сканируешь телефоном, открывается страница принтера, перетаскиваешь видео из SpinSlicer
и жмёшь «Печать». Пока идёт печать, на странице видно оставшееся время, скорость мотора и точность синхронизации.

```
 телефон / ПК ──Wi-Fi──► Raspberry Pi ──HDMI──► проектор
                              │
                              └──USB или 4 провода──► ESP32-S3 (экран, кнопки, мотор)
```

**Кадр по углу (с версии 0.5).** ESP32 считает каждый шаг мотора и знает угол флакона. SpinPi
20 раз в секунду пересылает этот угол программе [SpinProj](../SpinProj/README.md), а она на каждом
обновлении проектора показывает кадр, который принадлежит этому углу. Видео не может «уплыть»
от вращения, а свет гаснет ровно через N оборотов.
Старый способ (видео крутит mpv, Pi подгоняет мотор под видео) остался: `--engine mpv`.

> Попробовать всё без железа можно на компьютере: [`python3 dev/bench.py`](../README.md#весь-принтер-на-компьютере).

## Установка (один раз)

### Самый простой способ: одна команда на компьютере с Linux
SD-карта в картридере, из папки `SpinPrinter`:
```
sudo bash SpinPi/make_sd_card.sh
```
Скрипт найдёт карту и спросит «точно?». Спросит имя и пароль твоего Wi-Fi (пароль вводишь ты,
он не показывается; можно пропустить и подключить Pi к роутеру кабелем). Потом сотрёт всё
старое на карте, запишет Raspberry Pi OS Lite 64-bit, включит вход по SSH-ключу этого компьютера
(без пароля) и выключит любой текст на экране. SpinPi и SpinProj Pi поставит
сама при первом включении (10–20 минут, нужен интернет). Дальше: `http://spinslicer.local`.

Пункты 1–3 ниже — для Windows и Mac (или если скрипт не подходит). Подробно с картинками: [docs/INSTALL.ru.md](../docs/INSTALL.ru.md).

### 1. Записать систему на карту
1. Поставь **Raspberry Pi Imager** на компьютер (raspberrypi.com/software).
2. Устройство: **твоя модель Pi** (3, 3B+, 4, 5, Zero 2 W). Система: **Raspberry Pi OS Lite (64-bit)** (Other → Lite).
3. Нажми «Изменить настройки» (шестерёнка) и заполни:
   - имя хоста: **spinslicer**
   - имя пользователя и пароль (запомни!)
   - Wi-Fi: имя сети и пароль, страна RU
   - вкладка «Службы»: **включить SSH** (по паролю)
4. Записать. Вставить карту в Pi, подать питание и подождать 2–3 минуты.

### 2. Зайти на Pi с компьютера
В Windows открой «Терминал» (или PowerShell):
```
ssh твоёимя@spinslicer.local
```
Спросит «yes/no»: пиши `yes`, потом пароль (буквы при вводе не видны, это нормально).

### 3. Установить одной командой
В окне, где ты зашёл на Pi:
```
curl -fsSL https://raw.githubusercontent.com/v0xeII/SpinPrinter/main/SpinPi/get.sh | sudo bash
```
Она скачает SpinPi и SpinProj, поставит ffmpeg и python3-serial, соберёт SpinProj прямо на Pi,
запустит службу, сделает проектор чёрным до печати, освободит UART-пины для ESP и перезагрузит Pi
(10–20 минут). Запустить ещё раз = обновить.

### 4. Подключить
- ESP32 с экраном: USB-кабелем в Pi **или** 4 проводами к гребёнке ([схема](../docs/wiring.ru.svg)).
- Проектор: HDMI в Pi.
- На экране ESP: **Подключение** → QR-код с адресом.

## Как печатать

**Из SpinSlicer:** «Отправить на принтер». Слайсер сам находит принтер в сети (mDNS) и
отправляет файл `.spin`: видео одного оборота, превью детали и расчёт оборотов в одном файле.

**С флешки (как в OpenCAL):** скинь `.spin` или MP4 на флешку, вставь её в Pi. На экране принтера:
**Печать** → выбери видео → проверь скорость, экспозицию и паузу → розовая **ПЕЧАТЬ**.
Флешка подключается только для чтения, ничего на ней не меняется.

**По Wi-Fi:** открой страницу принтера (QR или `http://spinslicer.local`), перетащи `.spin` или видео,
нажми «Печать». Загруженные файлы тоже появляются в списке на экране принтера.

### Файл `.spin`
Один файл на одну печать: обычный ZIP без сжатия с `spin.json` (метаданные), `video.mp4`,
`preview.png` и `slicer.json` (формат описан в [docs/ecosystem.ru.md](../docs/ecosystem.ru.md)).
Принтер:
- проверяет `spin.json` (формат, версию) и SHA-256 видео, битый файл не принимает, а на флешке
  показывает с ошибкой;
- один раз распаковывает видео в `/var/lib/spinpi/spin/` (и с флешки тоже), превью показывает
  на странице и в окне печати;
- берёт из `plan` обороты и допуск (как раньше из тега MP4 или `имя.spin.json`), из `video` —
  `frames_per_rev` (сколько кадров в обороте), `frame0_angle_deg` (угол кадра 0) и `rotation`;
- если видео нарезано для вращения в другую сторону, чем крутится флакон (профиль принтера →
  «Флакон крутится»), кадры идут в обратном порядке: деталь выходит правильной, а не зеркальной;
- предупреждает, если файл нарезан для другого принтера (`printer.profile_id`).

Обычные видео, `имя.spin.json` рядом и JSON в теге MP4 работают по-прежнему.

### Профиль принтера и журнал
На странице «Профиль принтера» — то, что нужно слайсеру для расчёта: имя в сети, облучённость
и контраст проектора, диаметр, стенка и стекло флакона, передача и направление мотора.
Разрешение, частота, центровка и ширина флакона берутся сами. Хранится в `settings.json`,
слайсер забирает это через `GET /api/printer`. У принтера постоянный `id` (`spinpi-…`).

Журнал печатей (`GET /api/history`) хранит файл, расчёт, сколько оборотов было на самом деле,
поправку экспозиции, смолу и ответ «как получилось». По нему слайсер уточняет дозу смолы.

### Экспозиция без камеры: как это работает
OpenCAL просто крутит видео, пока человек не увидит деталь в камеру. Здесь время считается заранее:

1. **SpinSlicer** рассчитывает дозу по физике (поглощение смолы, облучённость проектора, доза
   гелеобразования) и кладёт расчёт в файл `.spin` (или прямо в MP4 и в `имя.spin.json` рядом).
2. **Принтер** превращает это в **целое число оборотов**: каждый угол получает одинаковую дозу.
   Если остановиться посреди оборота, часть углов получит лишнюю дозу, и деталь «перекосит».
   Свет гаснет ровно на границе оборота, потому что ESP знает угол флакона до шага.
3. **Калибровка смолы один раз:** в SpinSlicer есть «лесенка» из 9 столбиков с разной дозой.
   Печатаешь её, смотришь, какой столбик застыл первым, и вводишь номер. После этого расчёт
   совпадает с твоей смолой и твоим проектором.
4. **Обучение после каждой печати:** на экране «Готово!» выбери «Недосвет / Норма / Пересвет».
   Принтер сдвинет поправку экспозиции на величину допуска из расчёта, и следующая печать будет точнее.
   Все печати пишутся в журнал на странице.

Ещё принтер следит, чтобы доза была ровной:
- **кадр по углу:** SpinProj на каждом обновлении проектора показывает кадр для текущего угла
  флакона, поэтому видео не расходится с мотором, даже если мотор чуть гуляет;
- **прогрев проектора** (по умолчанию 5 минут с момента подключения по HDMI): пока лампа или
  светодиод не вышли на режим, печать ждёт в темноте;
- **пауза до света:** флакон сначала крутится в темноте, чтобы смола успокоилась;
- **частота кадров:** если fps видео не делит частоту экрана (24 к/с на 60 Гц), кадры показываются
  то 2, то 3 обновления экрана. Принтер предупредит: экспортируй 30 или 60 к/с;
- **аварии:** угол от ESP не приходит 0,3 с — SpinProj гасит свет сам; ESP молчит больше 1 с или
  мотор ушёл от скорости больше чем на 5 % — печать останавливается. Если пропала Pi, ESP сама
  останавливает мотор;
- **пропуски кадров** при декодировании считаются и показываются на экране и странице.

Видео без расчёта (старые, из OpenCAL с `_9rpm` в имени) тоже печатаются: обороты задаёшь сам.
Остановить печать можно на странице или на экране принтера (держать OK).

## Настройка проектора
Есть и на экране принтера (Сервис → Проектор), и на странице:
- **Сетка, Фокус, Круг, Белый**: тестовые картинки для фокуса. **Чёрный** гасит картинку.
- **Центровка**: показывает линию оси. Двигай её, пока она не совпадёт с осью вращения флакона.
  Это смещение потом применяется ко всем печатям.
- **Ширина флакона**: белая полоса шириной N пикселей. Подгони её под флакон, и ты узнаешь,
  сколько пикселей проектора приходится на флакон (это число нужно в SpinSlicer).

Не держи смолу под светом!

## Если что-то не так
- Логи: `journalctl -u spinpi -f`
- Перезапуск: `sudo systemctl restart spinpi`
- Проектор не показывает картинку: на странице будет красная строка с ошибкой проектора. Пришли её мне.
- Разрешение проектора не 1280×800: поменяй `--projector 1280x800` в `/etc/systemd/system/spinpi.service`
  (или `--projector auto`: взять разрешение, которое сообщает проектор),
  потом `sudo systemctl daemon-reload && sudo systemctl restart spinpi`.
- Замер, успевает ли Pi: `sudo systemctl stop spinpi && sudo /opt/spinpi/spinproj bench --rt --cpu 3`.

## Для разработчиков: HTTP API
| | |
|---|---|
| `PUT /api/files/<имя>` | загрузить `.spin` или видео (тело запроса = файл): `curl -T part.spin http://spinslicer.local/api/files/part.spin`. Ответ `{"ok":true,"name":…,"info":…}`; битый `.spin` → 400 `{"ok":false,"error":…}` |
| `GET /api/files` | библиотека (`id`: `lib/…` загруженные, `usb/…` с флешки): `format` (`spin`/`video`), кадры, fps, об/мин, `plan`, `plan_revs`, `tolerance_pct`, `rotation`, `frames_per_rev`, `frame0_angle_deg`, `reversed`, `other_printer`, `warnings`, `resin`, `preview`, `error` |
| `GET /api/thumb?id=…` | превью (PNG из `.spin` или кадр из видео, JPEG) |
| `GET /api/printer` | профиль принтера: `id`, `name`, `projector` (`width`, `height`, `hz`, `irradiance_mw_cm2`, `contrast`), `vial` (`diameter_mm`, `wall_mm`, `n_glass`), `calibration` (`offset_px`, `center_offset_px`, `vial_width_px`), `motor` (`gear`, `direction`), `software`; неизвестное = `null` |
| `POST /api/printer` `{"name":"Шкаф","vial_diameter_mm":25,"motor_dir":"cw_from_top"}` | изменить профиль (ещё `irradiance_mw_cm2`, `contrast`, `vial_wall_mm`, `vial_n`, `motor_gear`; `null` = неизвестно) |
| `GET /api/history` | `{"printer_id":…,"factor":…,"prints":[…]}`: каждая печать с `file`, `plan`, `plan_revs`, `revs`, `factor`, `exposure_pct`, `resin`, `result` (under / ok / over / null), `factor_after` |
| `POST /api/print` `{"id":"lib/print.mp4","revs":6,"factor":1.05,"delay_s":3}` | начать печать (`revs` можно не указывать: возьмётся из расчёта × поправка) |
| `POST /api/plan` `{"id":…,"factor":1.05}` | сколько оборотов и секунд получится, отклонение дозы, предупреждения |
| `POST /api/result` `{"result":"under"}` | как вышла последняя печать: under / ok / over |
| `POST /api/settings` `{"warmup_min":5}` | прогрев проектора, пауза до света |
| `POST /api/stop` | остановить |
| `POST /api/motor` `{"on":true,"rpm":4.0}` | покрутить мотор вне печати |
| `POST /api/projector` `{"pattern":"grid"}` | black / white / grid / focus / circle / center / vial |
| `POST /api/calibration` `{"offset_px":12,"vial_px":400,"show":"center"}` | центровка и ширина флакона |
| `GET /api/state`, `GET /api/events` | состояние (events = поток SSE, 2 раза в секунду) |
| `GET /api/wifi?scan=1`, `POST /api/wifi` `{"ssid":…,"psk":…}` | Wi-Fi (только в SpinOS) |

Без пароля: страницу видят все в твоей Wi-Fi сети. Для домашней сети это нормально.

**mDNS:** принтер объявляет себя как `_spinprinter._tcp` (порт 80) с TXT `name`, `id`, `api=1`,
`path=/api/printer`. Файл службы `/etc/avahi/services/spinprinter.service` пишет сам `spinpi.py`
(первую копию кладёт установщик). Проверить с компьютера: `avahi-browse -rt _spinprinter._tcp`.

**Тесты без Pi:** `python -m unittest discover tests` (Windows, Mac, Linux; ни ESP, ни ffmpeg не нужны).

`fake_esp.py` притворяется ESP32 (для проверки без железа); строки из файла `inject.txt` он шлёт как нажатия на экране.
Лучше [виртуальный ESP32](../SpinScreen_v0.7/sim/virtual_esp.cpp): это настоящий интерфейс экрана в окне.
