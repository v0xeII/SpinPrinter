Цель: число в градусах, а не «вроде не плывёт». Бюджет: ошибка угла меньше четверти кадра
(при 360 кадрах на оборот это 0,25°). Заполняй таблицы по ходу; пустая строка = не мерил.

## 6.1. Проектор без мотора

```bash
sudo systemctl stop spinpi && sudo /opt/spinpi/spinproj bench --rt --cpu 3 --seconds 60; sudo systemctl start spinpi
```

| поле строки RESULT | норма | замер |
|---|---|---|
| `missed` | 0 | |
| `fill_ms_max` | меньше периода кадра минус 3 мс (60 Гц: < 13,6) | |
| `vsync_sd_ms` | < 0,1 | |

Не проходит — дальше мерить нечего: сначала меньше разрешение или `isolcpus`.

## 6.2. Числа из самой печати

Сухой прогон 10 минут с водой вместо смолы, потом `GET /api/history`, последняя запись.

| поле | норма | замер |
|---|---|---|
| `sync_ms` | < 2 мс (4 об/мин: 0,05°) | |
| `missed_vsync` | 0 | |
| `dose_max − dose_min` | ≤ 1 обновление экрана на оборот печати | |
| `fill_ms_max` | как в 6.1 | |

## 6.3. Стробоскоп

```bash
python3 dev/make_strobe.py strobe.spin     # на Raspberry (нужен ffmpeg), файл в /api/files или на флешку
```

Бумажный диск с одной радиальной чертой на колбе, печать на 30 минут (обороты — сколько скажет
скрипт). Черта должна стоять неподвижно в четырёх положениях. Сними на телефон в замедленной
съёмке, кадр в начале и в конце положи рядом с отчётом.

| что видно | замер |
|---|---|
| уход фазы за 30 мин, ° | |
| размытие черты минус ширина вспышки, ° | |
| прыжки (сколько, когда) | |

Постоянная задержка проектора видна как одинаковый сдвиг всех четырёх положений: она только
поворачивает деталь в колбе, компенсировать не нужно.
